# WEB APPLICATION DEVELOPMENT : Assignment 2

A simple HTML & CSS meme generator page created for Assignment 2 - CSCS342 Web Application Development (Fall 2026).

## About

This page recreates a meme template using HTML and CSS, including:
- A photo styled with CSS
- A bold uppercase heading (meme title)
- A smaller italic caption below it

## Files

- `index.html` - the main webpage structure
- `style.css` - the styling for the meme layout
- `photo.jpg` - the meme image

## How to view

Download or clone this repo, then open `index.html` in any web browser.
